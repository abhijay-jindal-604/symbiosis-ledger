02 / 04  The mechanism
A stream is
a .yaml file in a git repo
Handler ID, federal waste codes, form code, available tons — one file per stream.
A claim is
a pull request against that file
The receiver states its own tonnage and its disclosed scheduling constraint.
Two claims are
a merge conflict, same line
Contention isn't modelled — git already has a primitive for it.
